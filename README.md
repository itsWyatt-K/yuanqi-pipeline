# yuanqi-pipeline（AI 影像产线）

> **v3.2.0 · 2026-09-23 · 双产线工位版**

我不是程序员，是用 AI 做短剧和电商图的创作者。被工具的交互体验卡住之后，我一条条试着重做，把能用的方案和技能卡整理在这里，可以直接装到 Open AI Canvas 上使用。

---

## 为什么做这个

做 AI 短剧和电商图，真正卡住我的不是模型能力，是交互：

1. **技能太多，不知道用哪个**：几百张提示词卡片铺开像一本字典，新手无从下手。
2. **对话框是黑盒**：不知道 Agent 装了什么技能、正在调用什么能力，只能猜。
3. **Agent 自说自话**：一句话没说清楚，它就自作主张跑一堆步骤，白烧算力。
4. **多步制作跑偏**：从主图、三视图做到详情页，脸变了、材质走样，前后对不上。
5. **推荐靠拍脑袋**：哪个技能好用、大家爱用什么，没有真实数据。

## 五个改动

### 1. 选包门房（`scene-recipe-concierge`）

**解决什么**：新手面对庞大的技能池，根本不知道选哪个。

**怎么做**：做了一个「门房」角色。当你说「我想做个视频」「帮我做张商品图」这种模糊话时，它用三个简单问题问清你到底要什么，然后把你送到对应的产线。**只推荐，不替你选。**

> 「门房」是这套体系里的固定角色名，也是技能在种子市场的检索名。下文沿用这个叫法，你搜「选包门房」就能装。

### 2. 引导式对话（基于 ask_user）

**解决什么**：Agent 接到指令直接开跑，猜错意图，浪费算力和时间。

**怎么做**：让 Agent 在关键分歧点先发起对话，把方向问清楚再动手。第一轮对齐意图，比事后返工便宜。

### 3. 对话框里的技能胶囊（PR #608）

**解决什么**：在聊天界面不知道当前能用什么技能，体验割裂。

**怎么做**：在对话框前端做出「技能胶囊」，最后打磨成单行分桶导航 —— 当前推荐的技能直接摆在输入框旁边，伸手就能点，不用记名字。

> 「胶囊」指对话框里那种圆角小按钮，点一下等于装载一个技能。

### 4. 工位化产线 + 产线事实表（PR #611）

**解决什么**：759 张卡片散着放，Agent 检索抓瞎；多轮制作之后产品或人设走样。

**怎么做**：

- **缩容**：收敛成短剧 6 个工位（S1–S6）和电商 7 个工位（E0–E7），给 Agent 刚好够用的上下文，让它能自己装配。
- **产线事实表**：不再一上来让你填十几项长表单，而是随工位推进逐步记下商品或角色的固定描述，几十步做完特征也不飘。

> 「工位」= 产线上的一个固定环节，一个工位对应一个技能卡、一个交付物。

### 5. 使用量统计（PR #590）

**解决什么**：推荐靠人工拍脑袋，不知道真实用户常用什么。

**怎么做**：在上游推动 usage telemetry，统计各工位的真实调用和反馈，让后续预设和技能排序由数据决定。

## 三十秒上手

1. **先装选包门房**：种子市场搜「`选包门房`」并激活。不知道从哪下手时，它用三个问题把你送到对的工位。
2. **装产线预设**：搜「短剧产线起步」或「电商产线起步」一键挂齐整条线；也可以逐个搜工位中文名安装。
3. **按工位走**：打开《双产线工位地图》→ 填一次《产线事实表》→ 从这条产线的第一个工位开始，一个工位交一个东西。
4. **只有一条纪律**：每个工位在调用付费生成之前，会把本批内容、数量、参数、参考图摊开给你看，**你确认了才执行**。

## 工位一览（中文真名在前，括号内为目录名）

### 短剧产线（S1–S6）

| 工位 | 技能名（目录名） | 什么时候用 |
|---|---|---|
| S1 | `短剧分镜表`（`jd-drama-shot-list`） | 有文字素材，要排镜头 |
| S2 | `角色资产板`（`jd-drama-asset-board`） | 要角色设定图、三视图、角色档案 |
| S3 | `影视提示词编译`（`jd-drama-prompt-compile`） | 要把意图写成提示词 |
| S4 | `首尾帧与镜头衔接`（`jd-drama-frame-bridge`） | 两段要接、要转场、要循环 |
| S5 | `跨镜一致性锁定`（`jd-drama-consistency`） | 换人、换背景、氛围不对、接着演 |
| S6 | `成片装配`（`jd-drama-assembly`） | 素材齐了，要剪成片并交付 |

### 电商产线（E0–E7）

| 工位 | 技能名（目录名） | 什么时候用 |
|---|---|---|
| E1 | `电商主图`（`jd-ec-main-image`） | 只有手机随手拍，要上架主图/副图 |
| E2 | `SKU变体矩阵`（`jd-ec-variant-matrix`） | 要多个配色/材质/款式变体 |
| E3 | `产品三视图`（`jd-ec-triview`） | 要多角度图、三视图 |
| E4 | `场景植入与氛围`（`jd-ec-scene-infuse`） | 商品要进场景、氛围要高级 |
| E5 | `平面海报排版`（`jd-ec-key-visual`） | 要海报、社媒图 |
| E6 | `产品运镜视频`（`jd-ec-product-video`） | 静态图要变成产品短片 |
| **E7** | `详情页长图产线`（`jd-ec-detail-page`） | 商品资料要做成一条完整详情长图（含竞品拆解） |
| E0 | `画质净化公共卡`（`jd-ec-quality-scrub`） | 画面油腻/塑料感/AI 味/噪点（公共附录） |
| 门房 | `选包门房`（`scene-recipe-concierge`） | 不知道选哪个、模糊需求先问路 |

> **检索提示**：技能商店 / 种子市场搜**中文名**（如「电商主图」「短剧分镜表」）即装；
> 英文目录名仅用于 GitHub 安装路径，不要当检索词用。

## 证据等级（如实说明）

> **两套编号不要混**：`E0–E7` / `S1–S6` 是**工位号**；`E1–E5` 是**证据等级**（E1 最高）。

| 等级 | 含义 | 本库现状 |
|---|---|---|
| **E1** | 当前版本 + 当前模型 + 真实交付物验证 | 工位 E1 主图 / E4 场景植入 / E5 平面海报 / E7 详情长图产线（2026-09-23 安途代步椅真实案例） |
| E2 | 跨版本/跨模型真实成片 | 暂无 |
| E3 | 可复现工作流，未复渲染 | 暂无 |
| **E4** | 成熟专业方法（出版书/行业方法）重铸 | 其余工位 + E0 公共附录 |
| E5 | 启发/未验证技巧 | 无（不得虚标） |

- 口径引自 `docs/PACK-UPGRADE-CONTRACT.md` v1.0；**没有 E1/E2 证据的卡必须标 E4 或 E5，不得虚标**——虚标比不标更糟。
- 电商线以「真实交付物」对应口径中的「真实成片」。
- 没有「装上就提升成片质量」的承诺。v2.0.0 时代的 A/B 记录留档在 `benchmarks/`，边界说明见各报告原文。
